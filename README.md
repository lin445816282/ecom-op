# 电商运营工作台

把 `G:\电商运营` 里的运营资料，整理成一个可直接使用的本地工作台：
- **网页**：可视化查看商品投产、运营知识、选品日历、SOP 任务。
- **脚本**：导入/导出 CSV、自动计算保本投产与目标投产等指标。
- **数据**：本地 JSON 存储，无需数据库。

## 文件结构

```
运营工作台/
├── index.html        单页前端
├── style.css         样式
├── app.js            前端交互
├── api.py            本地 HTTP 服务（端口 8765）
├── data.py           知识库 + 数据模型 + 指标计算
├── CLI.py            命令行工具
├── 启动工作台.bat     Windows 一键启动
├── 启动工作台.sh      Linux/macOS 一键启动
├── requirements.txt   可选依赖说明
└── data/
    ├── products.json  商品数据
    └── tasks.json     任务数据
```

## 快速开始

### Windows
双击 `启动工作台.bat`，或运行：

```bat
cd /d "G:\电商运营\运营工作台"
python api.py
```

浏览器打开：<http://127.0.0.1:8765>

### Linux / macOS
```bash
cd "/mnt/d/电商运营/运营工作台"
./启动工作台.sh
```

### 只算指标、不打开网页
```bash
# 查看当前商品指标
python CLI.py show

# 导入 CSV（列名支持：商品名/名称/name、到手售价/售价/selling_price、单件毛利/毛利/gross_profit 等）
python CLI.py import ./data/商品导入模板.csv

# 导出计算后的 CSV
python CLI.py export ./data/2026-08-商品投产.csv

# 重置为示例数据
python CLI.py reset
```

## 计算的指标

| 指标 | 公式 |
| --- | --- |
| 利润率 | 单件毛利 ÷ 实际到手售价 |
| 有效成交率 | 1 − 售后率 |
| 保本投产比 | 1 ÷ (利润率 × 有效成交率) |
| 目标投产比 | 保本投产比 × 1.2（建议缓冲） |
| 单笔成交花费上限 | 单件毛利 × 有效成交率 |
| 日预算建议 | 单笔成交花费上限 × 2 |

其中：
- **实际到手售价**：活动价、优惠券后、用户实际支付的价格。
- **单件毛利**：扣除成本、快递、运费险、平台扣点等。
- **售后率**：非标约 30%、半标约 20%、标品约 15%，可按实际数据调整。

## 使用建议

1. 先在“商品投产”里录入客单价、毛利和广告表现。
2. 优先看“保本 ROI”和“目标 ROI”，低于保本线的不建议持续放量。
3. 在“知识库”里学习测款、冷启动、拖价、主图、标题等方法。
4. 在“选品日历”里按节点提前 2-4 周准备。
5. 在“SOP 任务”里从模板创建每日任务并打勾。

## 合规声明

本工作台只收录符合平台规则和法律法规的长期运营方法，已剔除以下高风险动作：

- 刷单、改销量、虚假评价。
- 利用异常 SKU 价格或库存虚标制造销量。
- 恶意规避比价、货不对版、虚假宣传。
- 平台外导流、虚假发货、欺诈发货。
- 未经授权使用品牌词或盗图。

实际经营时请以平台最新规则中心和商家后台公告为准。
